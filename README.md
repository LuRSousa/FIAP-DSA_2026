# FIAP-DSA_2026

Repositório acadêmico da disciplina **Data Struct and Algorithms**, do curso de **Ciência da Computação da FIAP**.

O repositório tem como finalidade documentar o conteúdo desenvolvido ao longo da disciplina, reunindo exemplos de código, exercícios e atividades práticas realizadas durante as aulas.

## Sobre a disciplina

A disciplina apresenta fundamentos de **estruturas de dados, algoritmos e lógica de programação** utilizando **C** como linguagem principal.

Ao longo do ano, são abordados conceitos fundamentais de programação, estruturas de controle, manipulação de dados, análise de algoritmos e estruturas de dados.

Por se tratar de uma disciplina anual, o conteúdo é desenvolvido ao longo do **1º e 2º semestres de 2026**.

## Organização

O repositório está organizado em uma pasta para cada aula. Cada diretório contém os arquivos relacionados ao conteúdo e às atividades desenvolvidas naquele encontro.

> A estrutura será atualizada conforme novos conteúdos forem apresentados.

## Conteúdos

Até o momento, os seguintes conteúdos foram abordados:

| Conteúdo | Descrição |
|---|---|
| Operadores | Utilização de operadores aritméticos, relacionais e lógicos |
| Estruturas condicionais | Tomada de decisões utilizando estruturas como `if`, `else` e `else if` |
| Estruturas de repetição | Execução repetitiva de blocos de código utilizando estruturas como `for`, `while` e `do while` |
| Switch case | Estruturas de seleção múltipla utilizando `switch` e `case` |
| Vetores e Matrizes | Armazenamento e manipulação de conjuntos de dados |
| Notação Big O | Análise da complexidade e eficiência dos algoritmos |
| Struct | Criação e utilização de estruturas para organização de diferentes tipos de dados |
| Ponteiros | Manipulação de endereços de memória e referências a dados |

> Novos conteúdos serão adicionados ao longo do desenvolvimento da disciplina.
